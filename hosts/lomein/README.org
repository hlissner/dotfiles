#+title: Lomein
#+date:  August 30, 2009

* Overview
My living room PC, built from an old mac pro and spare parts. For casual use by
guests or family, using the household printer/scanner, or when I want to do some
pixel art/sketching on my cintiq.

* Filesystems
** =/dev/sda= :linux:
#+begin_src sh
parted /dev/sda -- mklabel gpt
parted /dev/sda -- mkpart ESP fat32 1MiB 1GiB
parted /dev/sda -- mkpart primary 1GiB 100%
parted /dev/sda -- set 1 boot on
mkfs.fat -F32 -n BOOT /dev/sda1
mkfs.ext4 -L root /dev/sda2

mount /dev/disk/by-label/root /mnt
mkdir -p /mnt/boot
mount /dev/disk/by-label/BOOT /mnt/boot
#+end_src
