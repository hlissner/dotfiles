* Overview
Spare parts from old systems. Serve as a workbench system for testing hardware,
deal with harddrives/old media en masse (like CDs, zip disks, SD cards, VHS
tapes, etc) or doing last minute CAD tweaks for 3d prints.

* Filesystems
** =/dev/sda= (SanDisk Ultra 3D NAND 500gb) :linux:
#+begin_src sh
parted /dev/sda -- mklabel gpt
parted /dev/sda -- mkpart ESP fat32 1MiB 1GiB
parted /dev/sda -- mkpart primary 1GiB 300GiB
parted /dev/sda -- mkpart primary 300GiB 100%
parted /dev/sda -- set 1 boot on
mkfs.fat -F32 -n BOOT /dev/sda1
mkfs.ext4 -L nixos /dev/sda2
mkfs.ext4 -L home /dev/sda3

mount /dev/disk/by-label/nixos /mnt
mkdir -p /mnt/{home,boot}
mount /dev/disk/by-label/BOOT /mnt/boot
mount /dev/disk/by-label/home /mnt/home
#+end_src
